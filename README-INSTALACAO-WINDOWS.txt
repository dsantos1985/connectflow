CONNECTFLOW — INSTALACAO NO WINDOWS (MODO DEMONSTRACAO)

1. Extraia o ZIP. Abra a pasta online-connectflow no VS Code.
2. Terminal integrado do VS Code: npm.cmd install
3. Depois: npm.cmd run dev
4. Navegador: http://127.0.0.1:5173
5. Login de demonstração: demo@connectflow.local / Demo@123456
6. Em Automações, encontre Qualificação de Lojistas e MEIs e os CNPJs públicos para testes.
7. O programa NÃO consulta Receita ou Sefaz e NÃO envia WhatsApp.

IMPORTANTE: O arquivo server/data.json e armazenado apos iniciar.
Guarde copia antes de trocar pastas.
Caso queira testar Meta webhook, trate as credenciais exclusivamente no backend e nunca publique ou compartilhe seus tokens.
