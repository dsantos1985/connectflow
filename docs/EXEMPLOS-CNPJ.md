Não presumir que são revendedores, contatos comerciais ou que o usuário tenha vínculo com eles. O código DEMO-OK é apenas simulação e NUNCA autoriza transferência real.

Contatos adicionais do CRM são inteiramente fictícios, com números reservados à simulação; não enviar mensagens. O banco de dados é criado localmente no primeiro início (`server/data.json`) e persistirá enquanto não for apagado. Faça backup desse arquivo antes de atualizar.
